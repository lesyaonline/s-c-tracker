# 📊 S&C Tracker

Веб-приложение для отслеживания инвестиционного портфеля.
Акции Московской биржи (MOEX) + криптовалюты CoinGecko.

## Структура проекта

```
sc_tracker/
│
├── main.py              — Flask-приложение: маршруты, валидация, API
├── database.py          — Работа с базой данных (users, assets, exchange_rates)
├── prices.py            — Рыночные данные: MOEX ISS API + CoinGecko + курсы валют
├── crypto.py            — Оригинальный CLI-скрипт (без изменений)
│
├── requirements.txt
│
├── templates/
│   ├── login.html       — Страница входа
│   └── dashboard.html   — Дашборд (виджет баланса, график, таблицы)
│
└── static/
    ├── css/
    │   └── style.css    — Все стили (светлая + тёмная тема, CSS-переменные)
    └── js/
        └── dashboard.js — Логика дашборда (загрузка данных, график, настройки)
```

## Как запустить

```bash
pip install -r requirements.txt
python main.py
```

Открыть: http://localhost:5000

## Функциональность

### Авторизация
- Вход по логину (без пароля)
- Ограничение: только буквы RU/EN, максимум 30 символов
- Валидация на клиенте (JS) и на сервере (Python re)

### Добавление активов
- Выбор из акций MOEX (12 тикеров) или криптовалют (7 монет)
- **Дата покупки** — стандартный календарный пикер (`input[type=date]`)
- **Количество акций** — только целые числа; криптовалюта — дробные
- **Цена** — вводится в USD; отрицательные и нулевые значения запрещены

### Расчёты (все в USD, единая валюта)
| Поле | Формула |
|------|---------|
| Инвестиции | цена покупки × количество |
| Баланс (текущая стоимость) | текущая цена × количество |
| Прибыль | баланс − инвестиции |

### Конвертация валют
- **USD** (по умолчанию), **₽ RUB**, **¥ CNY**
- Курс USD/RUB — MOEX валютный рынок (USD000UTSTOM)
- Курс CNY/RUB — ЦБ РФ (cbr-xml-daily.ru)
- Курсы кэшируются в `exchange_rates` БД по дате (один запрос в сутки)

### График
- Показывает реальную стоимость портфеля с даты первой покупки
- Акции: исторические данные MOEX history API
- Крипта: CoinGecko market_chart
- Без прогнозов и симуляций

### Настройки (⚙️ рядом с именем пользователя)
- Переключение валюты: USD / RUB / CNY
- Тёмная / светлая тема (сохраняется в localStorage)

## База данных (`portfolio.db`)

| Таблица | Назначение |
|---------|-----------|
| `users` | Логины пользователей |
| `assets` | Активы портфеля (цены хранятся в USD) |
| `exchange_rates` | Курсы валют по датам (кэш) |
